## 作业说明

本项目实现一个前后端分离的计算器。前端使用 HBuilderX 打开和预览，负责表达式输入、按键交互、结果展示和历史展示；后端使用 Python 标准库提供 HTTP API，负责校验、解析、计算、异常处理和 SQLite 持久化。

## 功能结构

```text
CalcSpace
├── 计算器
│   ├── 基础四则运算
│   ├── 复合表达式与括号
│   ├── 小数与一元正负号
│   └── 非法表达式、除零处理
├── 计算历史
│   ├── 保存历史
│   ├── 查询历史
│   └── 删除单条 / 清空全部
└── 前后端交互
    ├── POST /api/calculate
    ├── GET /api/history
    └── DELETE /api/history/{id}
```

## 设计与实现

### 前端

`app.js` 将请求集中在 `request()` 中。点击等号后只发送表达式字符串，结果和历史均来自后端 API；当后端不可用时，界面显示连接错误，不会在浏览器本地计算结果。页面还提供键盘输入、响应式布局和主题切换。

### 后端

`server.py` 先用白名单词法分析器切分数字、运算符和括号，再用调度场算法转换为逆波兰表达式，最后执行栈求值。这样可处理运算符优先级、括号、一元正负号、小数和除零错误，同时避免执行任意代码。每次成功计算通过参数化 SQL 写入 SQLite，查询或删除都直接操作数据库。

### 数据库

表 `calculation_history` 包含 `id`、`expression`、`result`、`created_at` 四个字段。刷新前端后再次请求 `/api/history`，可以验证历史仍由后端数据库提供。

## 运行与验收

1. 在 `calculator-backend` 目录执行 `python server.py`。
2. 用 HBuilderX 打开 `calculator-frontend`，运行 `index.html`。
3. 测试 `1 + 2 * 3`、`(1 + 2) * 3`、`-5 + 8`、`3 * -2`、`1 / 0` 和非法字符。
4. 刷新页面，确认历史仍然存在；删除单条记录后确认列表与数据库同步。
5. 停止后端，确认前端仍可输入，但不能得到新的有效结果。
